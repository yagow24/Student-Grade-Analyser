# 🎓 Student Grade Analyzer

A beginner-friendly Python project designed to manage student academic records, calculate grades, and analyze overall class performance.

## 📌 Project Overview

The Student Grade Analyzer is a menu-driven Python application that allows users to add multiple students, enter subject-wise marks, generate individual student reports, and view class performance summaries.

## ✨ Features

- Add multiple student records.
- Store student details using Python dictionaries.
- Enter subject names and marks.
- Calculate total marks and average.
- Automatically assign grades (A+, A, B, C, D, F).
- Determine Pass / Fail status.
- View individual and all student reports.
- Identify class topper and lowest scorer.
- Calculate class average.
- Display pass and fail counts and percentages.
- Prevent duplicate roll numbers.
- Handle invalid numerical inputs using Exception Handling.
- Validate subject counts and marks.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the `.ipynb` file using Google Colab or Jupyter Notebook.
3. Run all cells.
4. Follow the menu options to manage student records.
